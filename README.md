# Popsicle Pier sample app

A phone-first sample of the Popsicle Pier Swim School app: one parent's whole path from sign-up to the first "How it went" note. Made-up families, classes and prices; everything stays in the browser's localStorage.

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # Vitest
npm run e2e        # Playwright at 375x667, with axe
```

See CLAUDE.md for the rules, what's done and what's next, DECISIONS.md for the choices made along the way, and WALKTHROUGH.md for the six walk-throughs.
